# Code of Conduct

## Be Respectful

This is a learning project. Everyone is here to learn and improve.

## Expected Behavior

- Be respectful and constructive
- Help others learn
- Keep discussions focused on the code
- Be patient with questions
- Give credit where due

## Unacceptable Behavior

- Harassment or trolling
- Insulting or derogatory comments
- Publishing others' private information
- Other unprofessional conduct

## Learning Environment

This project is for learning. We encourage:

- Asking questions
- Making mistakes
- Trying new approaches
- Sharing knowledge

## Enforcement

Issues can be reported to:

**Vikas Singh** - [@xanderbilla](https://github.com/xanderbilla)

## Scope

This applies to all project spaces (issues, pull requests, discussions).

## Summary

Be kind, be respectful, and help each other learn.
